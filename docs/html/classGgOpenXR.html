詳解

OpenXR と OpenGL の相互運用を管理するバックエンド.

覚え書き
GLFW ウィンドウ、OpenGL コンテキスト、OpenXR ランタイムの橋渡しだけを担当し、 アプリケーション固有の画像生成や姿勢補正は行わない。 beginFrame() と endFrame()、および成功した beginView() と endView() は 必ず対にして呼び出すこと。
